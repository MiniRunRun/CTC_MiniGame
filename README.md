# CTC MiniGame

A *Digital Garden* browser minigame. First feature: a 3D flower builder. Hosted on GitHub Pages.

**Play:** https://minirunrun.github.io/CTC_MiniGame/

## Run locally

Needs Node.js 22+.

```bash
npm install
npm run dev
```

Open http://localhost:5173.
